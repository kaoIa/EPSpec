# Changelog

## 1.0.0

- Replaced the script-only demonstration with a durable LangGraph runtime.
- Added typed OpenAI Agents SDK planning and interpretation roles.
- Added isolated deterministic scientific workers and runtime-only EPSpec provider injection.
- Added run-scoped artifacts, provenance manifests, event tracing, timeouts, bounded concurrency, and cancellation.
- Added persistent run status, clarification, approval, and cross-process resume.
- Added CLI, REST/OpenAPI, SSE, MCP, doctor, evaluation, Docker, and Compose interfaces.
- Added credential-free, explicitly simulated end-to-end demonstrations.
- Preserved the original launchers and archived their example artifacts.
